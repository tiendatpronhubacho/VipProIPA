# TienDat IPA resource build fix

The CI workflows now run `Scripts/fix-ipa-resources.sh` after xtool has produced an IPA.

The script:
- Uses Apple's `actool` on macOS to compile `Resources/Assets.xcassets` into `Assets.car`.
- Merges the icon metadata generated by `actool` into the app Info.plist.
- Moves any `.lproj` folders nested under `Resources/` to the app bundle root without overwriting existing localization folders.
- Removes the raw asset catalog from the packaged app.
- Verifies that `CFBundleExecutable` resolves to a real file and that the bundle identifier remains `com.tiendat.ogios`.
- Repackages the IPA and verifies that it is a readable ZIP archive.

This script does not sign the app, alter gameplay patch payloads, or guarantee installation. A valid signing identity and matching provisioning profile are still required for installation on a device. The script must be run on macOS with Xcode command-line tools available.
