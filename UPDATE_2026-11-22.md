# TienDat source update — 2026-11-22

## Changes

1. Patch package loading
   - Removed the CI-only `/Users/builder/clone/ThreeOneOSFive` bootstrap path.
   - Bundled the repository `Patches` directory as an Xcode resource and copy valid `.3105`/`.3106` packages into Application Support on launch.
   - Downloads use `raw.githubusercontent.com`, validate HTTP 2xx and decode the package with `PatchPackageCodec.inspect` before atomic save.
   - Invalid cached packages are discarded and retried; missing/unreadable package names are collected in `PatchProjectStore.loadIssues` and the affected Patch rows now show a missing-package hint instead of appearing silently inactive.

2. Backend/build policy alignment with 3106
   - Backend precedence is kernel, then build-aware worse_query, then bad_query.
   - iOS 26.7.0–26.7.2 remains supported by worse_query.
   - iOS 27.0–27.2 is accepted; iOS 27.3.0 requires the exact verified build `24C5037i`; other 27.3 builds are rejected.
   - Runtime backend selection passes `AppInfo.osBuild`, so the build gate is actually enforced.

3. Sandbox diagnostics UI
   - Added `SandboxDiagnosticsView.swift` and registered it in the Xcode project.
   - Settings now opens the diagnostics screen.
   - Screen shows iOS version/build, device, selected backend, App Group, live probe action, recent grant result/path records, cache reset/re-probe, and copyable diagnostic report.
